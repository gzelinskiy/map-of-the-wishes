# «Небо побажань» — специфікація для розробки сайту

Цей пакет містить готовий дизайн мобільного сайту та опис того, як перетворити його на робочий сайт. Передай ШІ-асистенту (Claude, Cursor, v0, Lovable тощо) всю папку разом із цим файлом і промптом із розділу 10.

## 1. Суть

Особистий сайт-сховище всіх побажань, які автор щодня надсилав дівчині в Telegram. Сайт призначений для **пригадування**, а не для читання «сьогоднішнього» повідомлення (його вона отримує в Telegram).

Побажання поділені на дві категорії, і весь сайт побудований навколо цього поділу:

| Категорія | Метафора | Фон | Елемент на карті |
|---|---|---|---|
| **Добраніч** (ночі) | зоряне небо | темно-синє нічне небо, місяць, мерехтливі зорі, падаючі зорі, світлячки | зірка |
| **Добрий ранок** (ранки) | світанок | бузково-рожево-персиковий світанок, сонце, хмаринки, птахи | сонечко |

Пріоритет — **мобільна версія** (макети 390×844). На десктопі контент центрується колонкою до ~480px.

## 2. Файли в пакеті

```
screens/
  index.html          — головна: небо поділене хвилястим обрієм на ніч (верх) і світанок (низ)
  night-map.html      — карта зоряних ночей (довга сторінка, прокрутка)
  night-wish.html     — перегляд побажання на ніч (працює: стрілки, свайп, сусідні зірки)
  morning-map.html    — карта світанків
  morning-wish.html   — перегляд побажання на ранок (з анімацією «ніч розчиняється у світанок»)
data/
  wishes.sample.json  — приклад формату даних
DESIGN-SPEC.md        — цей файл
```

HTML-файли — це **еталон вигляду й анімацій**: самодостатні сторінки з інлайн-SVG і CSS. Їх можна відкрити в браузері телефона. Тексти й цифри в них — демо-дані, які треба замінити на реальні з даних.

## 3. Екрани та навігація

**Головна (`/`)**
- Заголовок «Небо наших побажань» і дата початку («з 20 січня 2026» — брати з першого повідомлення).
- Верхня половина — нічна картка: «Добраніч · N побажань під зорями» → `/night`.
- Нижня половина (під хвилястим обрієм) — ранкова картка: «Добрий ранок · N побажань на світанку» → `/morning`.
- На лінії обрію — кнопка «Згадати навмання»: відкриває випадкове побажання (будь-якої категорії).
- Кількості N рахуються з даних.

**Карта (`/night`, `/morning`)**
- Шапка: кнопка «назад», назва («Карта зоряних ночей» / «Карта світанків»), підзаголовок, перемикач-сегмент «Ночі | Ранки».
- Звивиста стежка згори донизу: **нагорі — найновіше побажання** (найяскравіша зірка/сонце з підписом дати), далі вниз — місяці у зворотному порядку, в самому низу — пагорби з будиночком і підпис «тут усе почалося · <дата першого побажання>».
- Кожне побажання — точка на стежці (зірка або сонечко). Точки згруповані по місяцях; біля кожного місяця — «таблетка» з назвою місяця та кількістю («Серпень · 31 ніч»).
- Тап по місяцю → перше (або останнє) побажання цього місяця; тап по точці → конкретне побажання (у реалізації точки мають бути кнопками з area ≥ 44px або тап по найближчій).
- Кількість місяців і точок генерується з даних, не захардкоджена.

**Побажання (`/night/:date`, `/morning/:date`)**
- Шапка: «назад» (до карти своєї категорії), над датою мітка категорії («ДОБРАНІЧ» / «ДОБРИЙ РАНОК»), дата («19 вересня»), справа — кнопка-перемикач на протилежну категорію **цього ж дня** (сонце на нічному екрані, місяць на ранковому). Якщо такого немає — кнопка неактивна або веде до найближчого дня.
- Над текстом — анімована зірка (ніч) або сонце (ранок).
- Текст повідомлення — **як є**, без штучного заголовка і підпису. Абзаци — за переносами рядків; емодзі з Telegram залишити як є.
- Показується **лише дата**, без часу.
- Низ: стрілки «попереднє/наступне» + міні-сузір'я з 3 сусідніх побажань (поточне підсвічене, дати під ними). Свайп вліво/вправо теж гортає.
- Без «улюблених» / лайків.

## 4. Дизайн-токени

**Шрифти (Google Fonts, усі з кирилицею)**
- Заголовки: `Cormorant Garamond` (italic 500/600)
- Рукописні акценти (дати на карті, підписи): `Caveat` 600/700
- Текст побажань: `Lora` 400, 19px, line-height 1.75
- Інтерфейс (мітки, кнопки): `Manrope` 600/700

**Кольори — Ніч**
- Небо: `#090C24 → #141840 → #231F4E → #2F2657` (вертикальний градієнт)
- Текст: `#F5EEDF` / `#FBF3E2`, другорядний `#CFC8EA`, приглушений `#B7B0D8`
- Акцент (зорі, активні елементи): золото `#F6C87A`, ядро зірки `#FFE9B8`
- Пагорби: `#231A40` (дальні), `#130F2C` (ближні), вікно будиночка `#FFC873`

**Кольори — Ранок**
- Небо: `#5E6FAE → #9A8CC4 → #E0AAB6 → #F6CBA6 → #FDE8CA`
- Текст: `#2A1F3D`, акцентний `#5E1F3E`, `#B8506A`
- Сонце: `#F7B267` / `#FFE2A6`, промінчики `#E0826A`, `#C2555E`
- Хмари: білі, прозорість 0.45–0.75; птахи `#4E2C49`

**Форма**: кнопки-кружечки 44–48px; «таблетки» радіус 16–28px; напівпрозорі підкладки (`rgba(255,244,220,.08)` на ночі, `rgba(255,255,255,.3–.6)` на ранку). Мінімальна зона дотику 44px. Контраст тексту ≥ 4.5:1.

## 5. Анімації (усі є в `screens/*.html`, CSS-класи в `<style>`)

| Клас | Де | Що робить |
|---|---|---|
| `.tw` | ніч | мерехтіння зірок, кожна з випадковою затримкою/тривалістю |
| `.shoot` | ніч | падаюча зірка; напрямок задається CSS-змінними `--dx`/`--dy` — **різні напрямки** (вниз-ліворуч, вниз-праворуч, майже вертикально, полого) і різні інтервали |
| `.firefly` | ніч, біля будиночка | світлячки блукають і пульсують |
| `.glow`, `.breathe` | обидві | м'яке «дихання» світла навколо зірок/місяця/сонця |
| `.nightfade` | ранкове побажання | при відкритті екран починається з нічного неба, яке за ~3с розчиняється у світанок |
| `.rise`, `.sunup` | ранок | сонце піднімається при появі |
| `.spin`, `.pulse` | ранок | повільне обертання та пульсація промінчиків сонця |
| `.ring` | ранок | світлі кільця розходяться від сонця й тануть |
| `.glint` | ранок | чотирипроменеві іскорки спалахують і повертаються навколо сонця |
| `.bird` + `.flap` | ранок | пташки перелітають небо, махаючи крилами |
| `.mote` | ранок | сонячні порошинки підіймаються й тануть |
| `.cross`, `.drift` | ранок | хмари пропливають через екран / погойдуються |
| `.draw` | карти | стежка «малює себе» (stroke-dashoffset) |
| `.pop` | карти, побажання | зірки/сонечка по черзі «спалахують» зі стаґером |
| `.up` | усі | поява тексту: зсув знизу + fade + blur; абзаци побажання — по черзі (+0.35с) і **повторюються при кожному гортанні** |
| `.press` | кнопки | стиснення при натисканні |

Обов'язково: `@media (prefers-reduced-motion: reduce)` вимикає рух (вже реалізовано в CSS).

Бажано додати в реальному сайті: плавний перехід між сторінками (View Transitions API: crossfade неба; при переході ніч↔ранок — зміна градієнта), ледаче завантаження далеких частин карти.

## 6. Дані

Формат (`data/wishes.json`):

```json
[
  { "id": "2026-09-19-night", "type": "night", "date": "2026-09-19", "text": "Добраніч, сонечко! ...\nДругий абзац..." },
  { "id": "2026-09-19-morning", "type": "morning", "date": "2026-09-19", "text": "Доброго ранку, моя хороша! ..." }
]
```

- `type`: `"night"` | `"morning"`
- `date`: ISO-дата (для нічних повідомлень, надісланих після 00:00, — відносити до попереднього дня)
- `text`: текст із переносами `\n`
- Час не зберігаємо й не показуємо.

### Як отримати дані з Telegram

1. Telegram Desktop → чат → ⋮ → **Export chat history** → лише текстові повідомлення, формат **JSON** → отримаєш `result.json`.
2. Скрипт (Node/Python) має:
   - взяти `messages`, де `from_id` = автор;
   - зібрати текст: поле `text` буває рядком або масивом частин (рядки та об'єкти `{type, text}`) — склеїти всі `text`;
   - визначити категорію: за ключовими словами (`добраніч`, `добрих снів`, `солодких снів`, `на ніч` → night; `доброго ранку`, `добрий ранок`, `ранок` → morning) з резервним правилом за годиною надсилання (05:00–12:00 → morning, 19:00–04:59 → night);
   - відкинути звичайну переписку, що не є побажанням (короткі повідомлення без ключових слів поза вікнами часу, стікери, фото);
   - нормалізувати дату (нічні після опівночі → попередній день);
   - зберегти `wishes.json`, після чого вручну переглянути сумнівні випадки.

## 7. Технічні рекомендації

- Статичний сайт: **Astro** або **Vite + vanilla/Preact**; сторінки генеруються з `wishes.json` (SSG). Без бекенду.
- Маршрути: `/`, `/night`, `/morning`, `/night/2026-09-19`, `/morning/2026-09-19`.
- Небо/пагорби/стежка — інлайн SVG; координати точок стежки генеруються з кількості побажань у кожному місяці (див. `night-map.html`: крива Catmull-Rom через вузли місяців, що чергуються ліворуч/праворуч).
- Мобільне: `viewport-fit=cover`, safe-area відступи, фон на весь екран (`min-height: 100dvh`), без горизонтального скролу.
- Хостинг: Netlify / Vercel / GitHub Pages / Cloudflare Pages. Оскільки тексти особисті — закрити доступ (простий пароль через Netlify/Cloudflare Access або неіндексоване посилання + `noindex`).

## 8. Доступність

Справжні `<a>` і `<button>`, `aria-label` на кнопках-іконках, `aria-current` для активного пункту, `aria-live="polite"` для тексту побажання, `lang="uk"`, декоративні SVG з `aria-hidden="true"`.

## 9. Що є демо в макетах

Кількості (243 ночі / 238 ранків), дати (20 січня — 19 вересня 2026), тексти трьох побажань кожної категорії — приклади. Усе має братися з `wishes.json`.

## 10. Готовий промпт для ШІ

> Зроби статичний мобільний сайт «Небо побажань» за специфікацією `DESIGN-SPEC.md`. Точно відтвори вигляд і анімації з файлів у `screens/` (це еталон — кольори, шрифти, SVG-сцени, CSS-анімації, розміри). Використай Astro (або Vite), дані бери з `data/wishes.json` у форматі з розділу 6; згенеруй сторінки головної, двох карт і перегляду кожного побажання, рахуй кількості й місяці з даних. Також напиши скрипт `scripts/import-telegram.(js|py)`, який перетворює `result.json` з експорту Telegram на `wishes.json` за правилами з розділу 6. Мобільна версія — пріоритет; перевір вигляд на ширині 360–430px. Не додавай «улюблене», заголовки чи підписи до побажань і не показуй час — лише дату.
